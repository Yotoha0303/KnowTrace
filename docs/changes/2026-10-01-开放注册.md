## 1. 这个开关会让谁能进来

**任何人**。注册端点在公网可达（经 Caddy → nginx → 应用 BFF → 认证服务），
**没有注册限流、没有邮箱验证**【实测】：

```
注册无限流中间件     ← RegisterHandler 里没有任何 limit/check
注册无邮箱验证       ← RegisterRequest 只有 username + password
```

## 2. 进来之后能看到什么【实测】

现有 **4 条记录全部是 `shared`**，由管理员 `go-user:1` 创建：

```
上线测试 / 测试 / 大模型训练工具链与 AI 智能体项目构想（关键词集）/ agent业务方向考虑
```

按 ADR-0015：「管理员创建的 Capture 默认标记为 `shared`。
普通成员拥有本人内容的写权限，并拥有**管理员共享内容的只读权限**。」

> **所以：任何注册成功的人，都能读到这 4 条记录**——
> 其中两条是用户的真实项目构想与业务方向。

**这不是 bug，是既定设计**（管理员内容默认共享）。但开放注册把它从
「可信小群体」扩大到了「任何知道域名的人」，**性质变了**。
