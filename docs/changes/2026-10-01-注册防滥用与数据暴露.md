## 1. 诊断：四个问题，一个净暴露

```

邮箱验证      ← RegisterRequest 只有 username + password
```

**任何人**可以脚本化批量建号。

### 问题 2：新用户**自动成为默认空间的 member**【依据：文件】

```ts
// src/features/workspace/service.ts:230
export async function ensureLegacyWorkspaceMembership(identity) {
  await db.insert(workspaceMemberships).values({
    workspaceId: LEGACY_DEFAULT_WORKSPACE_ID,      // ← 默认空间
    role: identity.isAdmin ? "owner" : "member",   // ← member

}
```

`resolveActorWorkspace` 每次都会先调它——**新用户首次访问即入默认空间**。

### 问题 3：member **能读 shared**【依据：文件】

```ts
// src/features/auth/resource-scope.ts:8
```

### 问题 4：**净暴露 = 2 条真实记录**【实测】

| 空间 | 记录 | 新用户 |

## 5. 执行结果

**填写时间：2026-10-01**

### 5.1 ❌ A1 执行失败 —— **而且失败暴露了一个更根本的机制**

**我按 A1 把 2 条改为 `private`，然后用管理员身份验证"仍可读"。
改完立刻复查，发现它们又变回了 `shared`。**

**【实测】复现（三步）**：

```text
步骤 1  设为 private                     → private / 2
步骤 2  以管理员身份发一个请求            → 触发 applyAdminSharingPolicy
步骤 3  再看                              → shared / 2      ← 被自动改回
```

**根因**【依据：`src/features/auth/access.ts:45`】：

```ts
async function applyAdminSharingPolicy(scope) {
  if (scope.isAdmin) {
    await db.update(captures).set({ visibility: "shared" })
      .where(and(workspaceId, createdById == 自己, visibility == "private"));
  }
}
```

**管理员每次解析访问权限时，都会把自己名下的 `private` 记录强行改回 `shared`。**

### 5.2 这条机制意味着什么（比原诊断更严重）

| 结论 | 说明 |
| --- | --- |
| **A1 不可行** | SQL 改会被系统自动回滚；**我提的方案错了** |
| **管理员永远无法拥有 private 记录** | 这是**强制转换**，不是"默认值" |
| **暴露面无法通过改数据消除** | 只要 `go-user:1` 是管理员，它的记录就必然是 `shared` |

**结合原诊断**（新用户自动进默认空间 + member 可读 shared）：

> **开放注册 ⇒ 任何注册者必然能读到管理员的全部记录。**
> **这不是配置问题，是三个机制叠加出的必然结果。**

### 5.3 ✅ 我的方案错在哪（如实记录）

我提出 A1 时**假设**「`private` 是一个可以设上去的状态」——
**没有先去读有没有机制会覆盖它**。

这与本会话反复出现的那条同源：
> **先假设了一个状态可以设，没先核实有没有东西会改它。**

**是"执行并验证"救了这个方案**——如果我改完就宣称完成，
用户会在某次访问后**静默地**重新暴露，而且**没有任何提示**。

### 5.4 那么还能做什么

| # | 选项 | 状态 |
| --- | --- | --- |
| **A2** | **关闭注册** | ✅ **唯一可行的零代码方案** |
| B1 | 改 `applyAdminSharingPolicy` 允许管理员私有 | ❌ 代码改动 = 新功能，用户已要求停止 |
| B2 | 让 `go-user:1` 不再是管理员 | ❌ 会失去管理能力，且不解决问题（换个管理员还是一样） |
| B3 | 新用户不自动进默认空间 | ❌ 代码改动 = 新功能 |

**所以：要消除暴露面，只有关闭注册这一条零代码路径。**
