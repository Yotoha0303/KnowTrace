## 已验证的关键故事

- 匿名可信环境的 Web 主流程完整回归。
- 使用真实 go-user-system 第二账号完成独立复核和可靠发布，并验证输入变化使旧复核失效。
- `/api/v1` 从幂等创建、读取、版本修改、对象时间线到带版本前置条件的删除完整通过。
- TypeScript、ESLint、单元测试、生产构建和 GitHub CI 作为每阶段提交门槛。

## 仍然不能声称的能力

- 不能声称 AI 或发布版本“永久正确”；任何结论仍应允许新证据证伪。
- 不能声称已有 Workspace/组织级多租户；当前隔离单位是单个创建者，管理员拥有实例级全局范围。
- 不能声称已有移动 App、离线同步、推送通知或应用商店交付。
- 不能声称已适合直接暴露公网；HTTPS、密钥托管、网络隔离和恢复演练取决于实际部署环境。
- 不能声称 KnowTrace 已能识别 CC-Switch 当前实际供应商；当前只能确认代理可达并测试当前路由的模型能力，供应商自动识别列为下一迭代前置项。

下一次迭代先关闭 CC-Switch 当前供应商自动识别缺口。随后再只选一个主目标：如小群体需要共享协作，优先增加 Workspace/组织分组与显式共享策略；如果仍以个人使用为主，则转为开发只读/记录优先的移动 App，而不是继续扩大 AI 自动决策权限。
