# BUG-001 保存后偶发找不到数据库

- 类型：Bug
- 状态：待修复
- 影响：用户保存内容后可能看到错误页
- 已知现象：AI 修改后过一段时间点击保存，提示找不到数据库
- 初步推断：可能与会话过期、数据库连接、错误提示误导或前端重试逻辑有关
- 需要补充的证据：前端请求、后端日志、数据库日志、复现步骤
- 验收标准：复现路径明确；错误提示准确；保存失败时不丢数据或新增本地保存
- 是否进入 PR：否，等定位原因后再开修复 PR



# BUG-002 账户无法登录

- 类型：Bug
- 状态：待修复
- 影响：用户登录时无法进行正常登录
- 已知现象：在账户和密码输入后，无法进入主界面，出现账号或密码错误的情况
- 初步推断：可能登录设备过多，导致后台数据库记录的会话限制了其他地方的登录导致的登录界面出现账号或密码报错的情况
- 需要补充的证据：前端请求、后端日志、数据库日志、复现步骤
- 验收标准：复现路径明确；多次登录同个账号后，不退出继续登录不出现账号或密码报错的情况
- 是否进入 PR：否，等定位原因后再开修复 PR



# BUG-003 手动添加个人主张和证据时，图片无法正常上传和通过AI审核

- 类型：BUG
- 状态：待修复
- 影响：上传的图片无法保存到对应的数据记录中，导致信息可靠性待验证
- 已知现象：在某条记录下，手动添加个人主张和证据的表单中，使用图片上传功能会出现图片格式不合适、图片上传失败等问题
- 初步判断：后端不接受常见的图片格式上传，导致无法上传。而图片格式符合上传条件后无法上传，可能是项目部署在公网后，由于安全性问题或者后端服务出现配置异常，导致无法上传和提交AI审核

- 需要补充的证据：前端请求、后端日志、数据库日志、复现步骤
- 验收标准：复现路径明确；手动上传图片时，上传的图片能够适配主流的照片格式，且图片能够正常上传和AI审核能够显性的说明无法审核的原因
- 是否进入 PR：否，等定位原因后再开修复 PR



# FEAT-004 AI整理的内容没有结构化

- 类型：FEAT
- 状态：待新增
- 影响：散乱的记录无法进行模板化和结构化记录，导致记录的内容混乱且只会修改错别字
- 已知现象：使用AI整理后，AI只能修改句子，没办法显性的结构化记录和协助使用者整理记录

- 验收标准：AI可提供模板或者内置模板，AI协助结构化记录
- 是否进入 PR：否



# FEAT-005 可以语言或文字输入给主界面的AI协助记录

- 类型：FEAT
- 状态：待新增
- 影响：避免长期半自动记录和信息审核，记录方式更加便携

- 是否进入 PR：否
