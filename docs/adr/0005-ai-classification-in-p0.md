# ADR-0005：分类与 AI 整理进入 P0

- 状态：accepted
- 日期：2026-08-14
- 替代：ADR-0003 的阶段划分

## 背景

用户明确将首版重点调整为记录内容、内容分类和 AI 辅助内容处理记录。如果 AI 整理继续留在 P1，首版无法验证项目最核心的差异化价值。

## 决策

P0 包含：

- Capture 与 Revision。
- Content Type 和扁平 Category。
- AI Run 与 Suggestion。
- AI 标题、摘要、类型、分类和语义候选。
- 用户接受、修改和拒绝建议。

事实核查、证据、可靠知识发布、RAG 和复杂展示继续延期。

## 原因

- 可以用真实输入验证 AI 分类是否有用。
- 保存和分类仍能形成一个小而完整的产品切片。
- AI 处理记录为以后 Prompt、模型和质量评估提供数据。

## 后果

- P0 需要至少一个真实 Provider Adapter。
- 测试必须覆盖 AI 故障隔离和结构化输出校验。
- 仍然禁止把 AI 建议称为已验证知识。
