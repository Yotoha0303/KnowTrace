# ADR-0010：AI 可靠性审查只生成有输入快照的非裁决建议

- 状态：accepted
- 日期：2026-08-15

## 背景

来源可访问和摘录匹配只能证明内容可追溯，不能证明来源权威、证据充分或主张真实。用户仍需要 AI 帮助检查可靠性与完整性，但若 AI 能直接修改状态或写入结论，就会绕过证据和人工审核边界。

## 决策

1. 新增 `claim_audit` AI 任务；复用现有 Provider 和请求级凭据机制。
2. 输入只包含主张、证伪条件、最新人工结论，以及已采纳、来源通过且摘录匹配的 Evidence 快照。
3. 每次成功审查追加 ClaimAIAudit，保存证据快照、证据指纹、Claim 时点、模型和结构化 Payload。
4. AI 只返回覆盖、平衡、问题、待补检查和建议 assessment；不能联网补证、写 Evidence、写 Review 或推进 Claim 状态。
5. 覆盖度、正反平衡、Evidence ID 白名单和边界提示由服务端确定或覆盖，不信任模型自报。
6. Claim 或有效证据集合变化后，历史 Audit 保留但在 UI 标记 stale。

## 结果

- AI 能帮助用户发现单一来源、缺少反例、范围和时效等问题，同时不会伪装成事实验证器。
- 每个建议都可以追溯到当时的证据集合和模型运行记录。
- 首版仍不提供来源权威性评级或自动检索；这些能力需要单独的来源模型、检索策略和更严格的安全设计。
